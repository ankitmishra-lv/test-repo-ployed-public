# Hello World Node Server

This repository contains a minimal Node.js HTTP server that responds with:

```text
Hello World
```

## Run locally

```sh
npm start
```

The server listens on port `3000` by default. You can override the host or port:

```sh
HOST=127.0.0.1 PORT=8080 npm start
```

## Validate

```sh
npm run check
```
