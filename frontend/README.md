# Todo Frontend

A self-contained React frontend for a todo application.

## Features

- Add, complete, edit, and delete todos.
- Filter by all, active, or completed tasks.
- Clear completed tasks in one action.
- Persists todos in browser local storage.
- Responsive layout for desktop and mobile screens.

## Getting Started

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
